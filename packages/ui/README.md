# @freighttech/ui 🎨

Composable UI toolkit for Open Mercato backoffice and business apps, maintained
by [FreightTech.org](https://freighttech.org).

`@freighttech/ui` includes backend UI patterns (DynamicTable, forms, dialogs,
detail sections, injections, notifications) and reusable primitives, built on
top of the Open Mercato framework.

## Why this package ✨

- 🧭 Consistent backoffice UX patterns out of the box
- 🧩 Rich primitives + higher-level business components
- ⚙️ Works with the Open Mercato injection architecture
- 🚀 Speeds up delivery without sacrificing flexibility

## Install

```bash
yarn add @freighttech/ui
```
